# Блог студента на Flask (ДЗ №12)

Проект представляет собой веб-приложение-блог, созданное на микрофреймворке Flask. 
В приложении рассказывается о навыках и достижениях студента, а также представлена таблица успеваемости.

## 📂 Структура проекта
- `app.py` — главный Python-файл для запуска сервера.
- `templates/index.html` — HTML-шаблон главной страницы.
- `static/style.css` — файл стилей.
- `static/avatar.png` — изображение профиля.

## 🚀 Запуск проекта
1. Установите Flask: `pip install flask`
2. Запустите приложение: `python app.py`
3. Перейдите по адресу: `http://127.0.0.1:5000`
